BoxKit 插件市场

GitHub 仓库 →
已安装 BoxKit 客户端？点击「导入到 BoxKit」在客户端内自动完成下载与安装。尚未安装？点「下载 .bkx」后，在客户端「设置 → 插件 → 安装插件包」选择该文件即可。
没有匹配的插件
发布插件：把插件目录（含 plugin.json）提交到仓库 plugins/ 下并 push，CI 会自动打包为 .bkx、更新清单并部署本页面。插件开发文档见仓库 docs/plugin-dev.md。
本页为纯静态站点，托管于 GitHub Pages；清单 manifest.json 同时供 BoxKit 客户端「设置 → 插件 → 插件市场」消费。
